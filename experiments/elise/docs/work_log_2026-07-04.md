## Submit Hardening

`submit/script.py`는 정상 예측 semantics를 유지하면서 실행 안전성을 보강했다.

- `MAX_LEN=640`, `BATCH=256` 유지
- serializer text output 유지
- `HF_HUB_OFFLINE` / `local_files_only=True` 유지
- `bias.npy` 로드 시:
  - 있으면 `float32`로 로드
  - shape `(14,)` 강제
  - 없으면 zero bias fallback
- batch OOM/failure fallback을 recursive half-batch 방식으로 변경
  - `256 -> 128 -> 64 -> ... -> 1`
- single sample까지 실패하면 기존처럼 `respond_only` fallback 유지
- normal path와 fallback path 모두 `logits += bias` 적용
